# Christian Tantardini — Personal Academic Website

Private development repository for Christian Tantardini's personal academic website.

## Project status

The website is being prepared as a private preview. Publication and permanent-domain configuration will be completed only after content review and handover.

## Planned sections

- Home and academic profile
- Publications
- Research projects
- Academic activities
- Curriculum vitae
- Contact and scholarly profiles

## Reference

The information architecture is inspired by a clear, multi-page academic profile model. The visual identity and implementation will be original and tailored to the scientist's research.
